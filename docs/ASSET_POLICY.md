# Sticker and asset policy

- All 14 vector stickers and four demo illustrations in `public/` were created specifically for Lovebug Booth. The source drawing generator is in `docs/generate_art.py`.
- The approval mockup in `docs/approved-sticker-playground-concept.png` is an original generated concept, not a screenshot of the finished app.
- Pinterest was used to explore kawaii scrapbook, bow, frame and cutout aesthetics. No Pinterest downloads are embedded in the app.
- If you add free-image resources later, keep a record of each asset's author, source URL, and license terms before publishing it in this public repository.
- Never add personal photos of either partner to the repository. Uploaded photos are kept in the browser and shared only when the user explicitly downloads/shares them.
